========================================================================
  1. FROZEN-INVENTORY VALUE FUNCTION
========================================================================
Under arithmetic Brownian motion  dS = sigma dW  and CARA utility
  U(W) = -exp(-gamma * W),
the frozen-inventory (q fixed) HJB equation admits the closed form:

  v(x,s,q,t) = -exp(-gamma*x) * exp(-gamma*q*s)
               * exp( gamma^2 * q^2 * sigma^2 * (T-t) / 2 )

LaTeX:
  v = - e^{- \gamma x} e^{- \gamma q s} e^{\frac{\gamma^{2} q^{2} \sigma^{2} \left(T - t\right)}{2}}


========================================================================
  2. RESERVATION PRICES
========================================================================
The optimal reservation prices satisfy:

  r^a = s + (1 - 2q)*gamma*sigma^2*(T-t)/2
  LaTeX: r^a = \frac{\gamma \sigma^{2} \left(1 - 2 q\right) \left(T - t\right)}{2} + s

  r^b = s + (-1 - 2q)*gamma*sigma^2*(T-t)/2
  LaTeX: r^b = \frac{\gamma \sigma^{2} \left(T - t\right) \left(- 2 q - 1\right)}{2} + s

  r   = s - q*gamma*sigma^2*(T-t)  (reservation mid)
  LaTeX: r = - \gamma q \sigma^{2} \left(T - t\right) + s


========================================================================
  3. THETA-ANSATZ DERIVATION OF RESERVATION PRICES
========================================================================
Substituting u = -exp(-gamma*x)*exp(-gamma*theta(s,q,t)) into the HJB
equation and using the approximate solution
  theta(s,q,t) = q*s - (q^2/2)*gamma*sigma^2*(T-t)
yields:

  r^b from theta: - T \gamma q \sigma^{2} - \frac{T \gamma \sigma^{2}}{2} + \gamma q \sigma^{2} t + \frac{\gamma \sigma^{2} t}{2} + s
  r^b direct:     \frac{\gamma \sigma^{2} \left(T - t\right) \left(- 2 q - 1\right)}{2} + s
  Consistent:     True

  r^a from theta: - T \gamma q \sigma^{2} + \frac{T \gamma \sigma^{2}}{2} + \gamma q \sigma^{2} t - \frac{\gamma \sigma^{2} t}{2} + s
  r^a direct:     \frac{\gamma \sigma^{2} \left(1 - 2 q\right) \left(T - t\right)}{2} + s
  Consistent:     True


========================================================================
  4. SYMBOLIC IDENTITY VERIFICATION
========================================================================
  Midpoint identity  (r^a+r^b)/2 == r :  True
  Spread identity    r^a - r^b == gamma*sigma^2*(T-t) :  True


========================================================================
  5. LIQUIDITY TERM AND QUOTE DISTANCES
========================================================================
  L(gamma,k) = (1/gamma)*ln(1 + gamma/k)
  LaTeX: L = \frac{\log{\left(\frac{\gamma}{k} + 1 \right)}}{\gamma}

  delta^a = \frac{\gamma \sigma^{2} \left(1 - 2 q\right) \left(T - t\right)}{2} + \frac{\log{\left(\frac{\gamma}{k} + 1 \right)}}{\gamma}

  delta^b = \frac{\gamma \sigma^{2} \left(T - t\right) \left(2 q + 1\right)}{2} + \frac{\log{\left(\frac{\gamma}{k} + 1 \right)}}{\gamma}

  Total spread identity delta^a+delta^b == gamma*sigma^2*(T-t)+2L:  True


========================================================================
  6. EQUATION-FAITHFUL vs TABLE-FAITHFUL SPREAD
========================================================================
Equation-faithful total spread (from Eq. 13 in the paper):
  spread_eq = gamma*sigma^2*(T-t) + (2/gamma)*ln(1 + gamma/k)

  This includes the inventory-risk component gamma*sigma^2*(T-t)
  which vanishes at t = T.

Table-faithful spread (numerical tables in the paper use only the
  liquidity component, evaluated at q=0 / t=T):
  psi(gamma,k) = (2/gamma)*ln(1 + gamma/k)

  LaTeX: psi = \frac{2 \log{\left(\frac{\gamma}{k} + 1 \right)}}{\gamma}

  Numerical values of psi for default k=1.5:
    gamma= 0.01  =>  psi = 1.3289
    gamma= 0.10  =>  psi = 1.2908
    gamma= 0.50  =>  psi = 1.1507


========================================================================
  7. EXPONENTIAL INTENSITY DERIVATIVE
========================================================================
  Intensity model: lambda(delta) = A * exp(-k*delta)
  Derivative check: d(lambda)/d(delta) + k*lambda == 0
  Result: True
